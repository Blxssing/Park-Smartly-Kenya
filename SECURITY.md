# Security Policy

## Project status

ParkSmart Kenya is an early-stage educational prototype. It is not designed or reviewed for production deployment, real payments, personal-data processing, or physical access control.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if enabled. Otherwise, contact the repository maintainer privately through the contact method listed on the maintainer's GitHub profile. Include the affected component, reproduction steps, potential impact, and any suggested mitigation.

Please allow reasonable time for investigation and a fix before public disclosure.

## Safe use

- Bind the demo server to localhost unless it has been independently hardened.
- Do not use real payment credentials or customer records.
- Do not connect this prototype to physical gates, barriers, or vehicle-control hardware.
- Do not commit secrets, tokens, or private data.
